# 🎮 ЯРИС ловит ТРАФИК с ДОРОВ

## Интерактивная игра от SEO агентства Marketsek

**Помогите Ярису ловить биткойны и трафик с доров!**

### 📖 Описание

Это веселая HTML5 игра, созданная на движке Phaser. Ваша задача - помочь Ярису (волку с надписью на майке) ловить биткойны, которые падают с неба. Чем больше биткойнов вы поймаете, тем выше ваш уровень!

### 🎮 Как играть

**Управление:**
- **Стрелки влево/вправо** или **A/D** - движение Яриса влево/вправо  
- **Стрелки вверх/вниз** или **W/S** - поднять/опустить корзину для ловли

**Цель:**
- 💰 Ловите падающие биткойны
- За каждый пойманный биткойн вы получаете 1 точку
- ⚠️ Пропустили 3 биткойна - КОНЕЦ ИГРЫ!
- 📈 Каждые 5 поймаемых биткойнов - новый уровень!
